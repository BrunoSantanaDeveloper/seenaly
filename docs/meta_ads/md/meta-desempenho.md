# Guia de Metas de Desempenho e Lances

Aprenda a mapear objetivos de marketing, configurar eventos de conversão e estruturar orçamentos mínimos recomendados para maximizar o leilão.

## O que é a Meta de Desempenho?

Ao selecionar a **Meta de Desempenho** para um conjunto de anúncios, você escolhe exatamente qual evento acionará a inteligência artificial para otimizar os lances no leilão. O aprendizado de máquina trabalhará continuamente para obter o maior volume dessa métrica ao menor custo possível.

*Exemplo:* Se você seleciona o objetivo de campanha **Vendas**, o sistema permite otimizar no nível do conjunto de anúncios tanto para **Maximizar cliques no link** (focado em cliques rápidos) quanto para **Maximizar o número de conversões** (focado em compradores reais). O Pixel ou SDK é requerido para metas baseadas em conversões e valores.

## Relação entre CPA Desejado e Orçamento Mínimo

Algumas metas de desempenho exigem maior volume e maturidade de verba. Para garantir a fase de aprendizado, **seu orçamento diário deve ser de pelo menos 10 vezes o custo médio estimado por resultado.** Caso contrário, a campanha sofrerá de subveiculação ou aprendizado limitado.

### Limite de Lance vs. Custo Médio

**Limite de Lance:** Define o teto máximo que você quer pagar para vencer leilões individuais. Evita picos de custo, mas pode travar a entrega se for baixo demais.

**Meta de Custo por Resultado:** Define a média de custo desejada a longo prazo. Oferece mais flexibilidade para a inteligência artificial buscar oscilações positivas.

### Otimização de ROAS

Para maximizar o valor das conversões (ROAS), o Pixel da Meta deve registrar o valor dinâmico das transações nas faturas da loja. Esta meta requer histórico constante de eventos ativos na conta para calibrar o algoritmo de intenção de compra.
