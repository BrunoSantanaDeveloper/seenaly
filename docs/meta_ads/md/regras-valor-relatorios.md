# Como usar o detalhamento das regras de valor para relatórios no Gerenciador de Anúncios da Meta

As regras de valor permitem que você expresse valor em critérios de público, posicionamento e local da conversão, além de consolidar campanhas para impulsionar o desempenho. Quando você usa regras de valor, suas campanhas podem ajustar a veiculação de acordo com os critérios e os resultados que você valoriza mais. Depois de criar uma campanha usando regras de valor, é possível ver um detalhamento nos relatórios no Gerenciador de Anúncios da Meta.

## Como usar o detalhamento das regras de valor para relatórios no Gerenciador de Anúncios da Meta

Para ver os relatórios de campanhas usando regras de valor no Gerenciador de Anúncios da Meta:

1. Acesse o Gerenciador de Anúncios.

2. Selecione uma campanha que use regras de valor.

3. Clique no menu suspenso Detalhamento. Selecione o detalhamento Regras de valor. Observação: esse detalhamento exibe apenas o desempenho de conjuntos de anúncios e anúncios.

Agora você deve conseguir ver os resultados, como conversões, de cada regra de valor no seu conjunto de regras de valor. Com base nos seus resultados, você pode determinar se deve ajustar suas regras de valor.

Para avaliar se as regras de valor estão gerando resultados relevantes para você, é possível focar em métricas principais, como eventos de conversão ou impressões. Como as regras de valor priorizam resultados de alto valor, é importante avaliar se elas estão direcionando os gastos de forma eficaz para esses resultados mais valiosos.

Observação: pode ser necessário utilizar outras ferramentas de análise para validar melhor as melhorias nos indicadores da parte inferior do funil.
