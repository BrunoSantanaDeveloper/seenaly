## Ferramentas para Estúdio Domiciliar e Edição

Você não precisa de orçamentos milionários de produção. O hardware básico do seu dispositivo móvel e poucas ferramentas domésticas bastam:

### Como Montar um Estúdio de Baixo Custo

Utilize materiais comuns para elevar a qualidade estética instantaneamente:

- **Iluminação Natural:** Grave próximo a janelas durante o dia para ter luz difusa e suave.

- **Papel-Pluma (Foam Board):** Posicione placas brancas no lado oposto à luz para atuar como rebatedores de sombra.

- **Minitripé:** Evite tremores e garanta estabilidade para gravação de vídeos curtos.

- **Papel Contato Decorativo:** Forre superfícies lisas para criar texturas de fundo consistentes (ex: imitação de madeira ou mármore).

### Aplicativos de Suporte recomendados

Utilize ferramentas móveis gratuitas para refinar os criativos:

- **Mojo:** Ideal para criar pequenas animações, transformando imagens estáticas de produtos em vídeos dinâmicos com tipografia.

- **Videoshop:** Excelente para cortar trechos, combinar múltiplos clipes de gravação, realizar gravações em stop-motion e redimensionar proporções rapidamente.
