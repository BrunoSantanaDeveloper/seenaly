# Como preparar sua empresa para usar a API de Conversões

Se você já ouviu falar [sobre a API de Conversões](api-conversao.md), pode estar se perguntando como começar. As equipes de marketing frequentemente consultam diferentes partes interessadas nas suas organizações para considerar o tempo, os recursos e os benefícios de usar a API de Conversões antes de priorizarem e executarem a sua implementação.

Esta lista pode ajudar ao longo do processo de tomada de decisão e preparar você e as partes interessadas do seu negócio a usar a API de Conversões:

- **Entenda como a sua empresa pode se beneficiar com a API de Conversões.** A API de Conversões foi desenvolvida para criar uma conexão direta entre os dados de marketing dos anunciantes e os sistemas da Meta. Isso ajuda a otimizar o direcionamento de anúncios, diminuir o custo por ação e mensurar os resultados. Saiba mais [sobre os benefícios de usar a API de Conversões](api-conversao.md) e veja [como outras empresas encontraram sucesso](https://www.facebook.com/business/success/categories/conversions-api).

- **Escolha o seu método de configuração e verifique se tem os recursos de que precisa.** Diferentes opções de configuração requerem diferentes recursos e capacidades técnicas. Por exemplo, configurar a API de Conversões usando a configuração habilitada pela Meta ou uma integração de parceiro pode ser mais fácil e rápido, enquanto as integrações diretas são mais personalizadas e exigem suporte de desenvolvedores. [Compare as opções de configuração da API de Conversões.](comparar-opcoes-configuracoes-api.md)

- **Leve em consideração as partes interessadas e entre em contato com elas antes.** Conseguir a adesão das partes interessadas pode ser um processo demorado. É recomendável entrar em contato com elas logo no início. Você pode compartilhar os recursos a seguir para orientar a conversa:

  - **Executivos de marketing e responsáveis por decisões comerciais:**

    - [Breve introdução à API de Conversões](https://www.facebook.com/business/tools/facebook-conversions-api)

    - [Estudos de caso da API de Conversões](https://www.facebook.com/business/success/categories/conversions-api)

  - **Assessoria jurídica:**

    - [Privacidade e uso de dados para as Ferramentas da Meta para Empresas](https://www.facebook.com/business/help/PrivacyBestPractices)

    - [Termos das Ferramentas Comerciais](https://www.facebook.com/legal/terms/businesstools)

  - **Desenvolvedores e equipes de tecnologia:**

    - [Comparar as opções de configuração da API de Conversões](comparar-opcoes-configuracoes-api.md)

    - [Sobre integrações de parceiros para web](https://www.facebook.com/business/help/WebPartnerIntegrations)

    - [Começar a usar a API de Conversões](https://developers.facebook.com/docs/marketing-api/conversions-api/get-started)

    - [Boas práticas para usar a API de Conversões](boas-praticas-api-conversao.md)

  - **Equipes de mensuração e análise:**

    - [Sobre testes de Conversion Lift](https://www.facebook.com/business/help/221353413010930)

- **Desenvolva uma linha do tempo que contemple as aprovações das partes interessadas e seu método de configuração.** A implementação da API de Conversões pode levar de horas a semanas ou meses, dependendo de vários fatores. Por exemplo, o [método de configuração](comparar-opcoes-configuracoes-api.md) escolhido e o processo de tomada de decisão das partes interessadas. Defina uma linha do tempo que contemple todas ou algumas das ações a seguir:

  - Obter a adesão das partes interessadas.

  - Integrar a equipe técnica e o parceiro de soluções, se for o caso.

  - Preparar-se para a análise adicional das suas obrigações de conformidade conforme as leis de regulamentação de dados, além de aprovar o compartilhamento de dados com a sua equipe jurídica. O uso e o compartilhamento de dados das Ferramentas da Meta para Empresas são regidos pelos nossos [Termos das Ferramentas Comerciais](https://www.facebook.com/legal/terms/businesstools) e (conforme aplicável) os [Termos da Plataforma](https://developers.facebook.com/terms).

  - Configure a API de Conversões. Cada método de configuração exige uma quantidade de tempo diferente. [Comparar as opções de configuração da API de Conversões.](comparar-opcoes-configuracoes-api.md)

  - Testar a sua conexão de dados. [Assista a este tutorial em vídeo sobre como testar a sua primeira chamada de API.](https://developers.facebook.com/docs/marketing-api/conversions-api/using-the-api#video)
