## Desempenho e volume de anúncios

O número de anúncios ativos na sua conta de anúncios ou na sua Página exerce uma função importante na obtenção de resultados previsíveis, estáveis e otimizados.

Sempre que um anúncio é exibido, nosso sistema de veiculação de anúncios obtém mais informações sobre qual é o melhor público para o anúncio e quais são os melhores locais para exibi-lo. Quanto mais um anúncio for exibido, melhor o sistema de veiculação se tornará na otimização do desempenho do anúncio.

Quando um anunciante veicula muitos anúncios de uma vez, cada anúncio é veiculado com menos frequência. Isso significa que menos anúncios saem da fase de aprendizado e que mais orçamento é gasto antes de o sistema de veiculação poder otimizar o desempenho. Em outras palavras, um número excessivo de anúncios pode resultar em pior desempenho.

Para alcançar resultados mais previsíveis, estáveis e otimizados, os anunciantes devem monitorar o volume de anúncios ativos e não exceder o limite por Página de anúncios que estejam em veiculação ou em análise. Saiba mais sobre os limites de anúncios.

Testar novas estratégias de marketing e criativos ainda é importante. No entanto, os anunciantes devem equilibrar essas táticas garantindo que o sistema de veiculação tenha ampla oportunidade de aprender sobre cada anúncio.

## Boas práticas

As táticas abaixo podem ajudar você a gerenciar o volume de anúncios.

1. Combine conjuntos de anúncios. A combinação de conjuntos de anúncios ajudará você a conseguir as conversões de que precisa para sair da fase de aprendizado mais cedo. Se você gerar relatórios sobre resultados para cada público, combine conjuntos de anúncios e use detalhamentos para relatórios granulares que não prejudicam o desempenho.

2. Se você direcionar para pequenas áreas geográficas, combine conjuntos de anúncios em áreas geográficas maiores para agregar conversões e aprendizados de veiculação entre conjuntos de anúncios.

3. Se estiver criando diferentes conjuntos de anúncios para posicionamentos distintos, combine conjuntos de anúncios e use os posicionamentos Advantage+ e a personalização de ativo. A personalização de ativo permite escolher os ativos ideais para cada posicionamento de um único anúncio.

4. Se você estiver criando diferentes conjuntos de anúncios para diferentes idiomas, combine conjuntos de anúncios e defina vários idiomas em um único conjunto de anúncios. Se você estiver usando anúncios de catálogo Meta Advantage+, poderá criar um anúncio de catálogo Advantage+ para vários idiomas e países adicionando um feed de idioma e/ou país ao seu catálogo.

5. Reduza os anúncios por conjunto de anúncios, mas mantenha ativos de criativo diversificados por conjunto. Um anúncio pode conter vários ativos de criativo (até 10). Se você testar muitas variáveis de texto, use a otimização de texto múltiplo. Geralmente, um anúncio com várias opções de texto é mais eficaz do que vários anúncios sem essa otimização, porque permite que o sistema de veiculação otimize automaticamente para o desempenho de cada impressão do anúncio.

6. Se você testar muitas variáveis de criativo, use o criativo dinâmico. Isso permite que o sistema de veiculação encontre o melhor criativo para veicular para um determinado usuário, enquanto usa apenas um anúncio.

7. Se você testar vários formatos, use o criativo Advantage+ para catálogo. O criativo Advantage+ para catálogo ajuda a mostrar diferentes formatos e criativos para as pessoas com base em a que elas têm maior probabilidade de responder.

8. Use soluções específicas do setor. A Meta oferece muitas soluções para atender às necessidades específicas do setor para um alto volume de anúncios. Com essas soluções, você pode usar menos anúncios enquanto ainda promove todo o seu catálogo de produtos. Se o seu objetivo é aumentar o reconhecimento de várias lojas físicas, use os recursos de localização da loja para personalizar anúncios com informações locais e criativos para cada uma das suas lojas.

9. Se você anuncia vários produtos para o mesmo público, use os anúncios de catálogo Advantage+. Os anúncios de catálogo Advantage+ permitem que o sistema de veiculação otimize automaticamente os melhores produtos para cada pessoa.

10. Se você anuncia muitos imóveis, combine os conjuntos de anúncios e use anúncios imobiliários para mostrar às pessoas os anúncios das propriedades que elas estão mais propensas a comprar.

11. Se você anuncia um inventário automotivo, use anúncios de inventário automotivo para promover todo o seu inventário de veículos com menos anúncios.
