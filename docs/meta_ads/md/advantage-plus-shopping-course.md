## Sinais de Dados e IA Generativa no Criativo

Criativos dinâmicos e sinais estruturados são os pilares da IA da Meta. Sem dados precisos coletados via **Meta Pixel e API de Conversões (CAPI)** redundantes, a otimização automática perde eficácia.

### Checklist de Sinais Saudáveis (API de Conversões + Pixel)

✓ **Deduplicação de Eventos:** Envie o mesmo `event_name` e `event_id` idênticos tanto pelo Pixel quanto pelo servidor (CAPI) para que a Meta descarte registros duplicados.

✓ **Qualidade de Correspondência (Event Match Quality):** Insira parâmetros como Hashed Email, Click ID e IP do usuário para elevar a pontuação de cruzamento.

✓ **Velocidade de Transmissão:** Envie os eventos em tempo real para evitar janelas de atraso na otimização de públicos no leilão.

## Medindo Resultados: Estudos de Lift de Conversão

A melhor forma de comprovar se a automação Advantage+ de fato superou o modelo manual (constrained setup) é o **Estudo de Conversion Lift (Incrementalidade)**. Ele separa sua audiência em um grupo exposto e um grupo controle para isolar o real impacto da mídia.
