# Sobre o Gerenciador de Eventos da Meta

> Caso use um conjunto de dados, você poderá ver uma experiência diferente no Gerenciador de Eventos da Meta.

O Gerenciador de Eventos da Meta permite visualizar e gerenciar os dados dos seus eventos. Você pode configurar, monitorar e solucionar problemas com integrações, como a [API de Conversões](api-conversao.md), o [Pixel da Meta](meta-pixel.md) e o SDK do Facebook para iOS e Android.

Além disso, o Gerenciador de Eventos permite comparar as atividades nas fontes da sua empresa ao longo do tempo e criar públicos.

## Gerenciador de Eventos da Meta

O Gerenciador de Eventos tem cinco menus no lado esquerdo: **Conectar dados**, **Visão geral**, **Fontes de dados**, **Conversões personalizadas** e **Integrações de parceiros**.

## Visão geral

A página de visão geral oferece um resumo dos dados do seu evento, destacando problemas e recomendações para melhorar o desempenho e a mensuração dos anúncios.

## Fontes de dados

Na página **Fontes de dados**, selecione seu conjunto de dados para ver insights e ferramentas de gerenciamento. Diferentes tipos de dados podem mostrar abas diferentes no topo da página.

| Aba | Descrição | Recursos |
| --- | --- | --- |
| **Visão geral** | Fornece uma visão geral das atividades dos eventos. | **Atividade de eventos:** mostra métricas em gráfico para acompanhar alterações ao longo do tempo. **Tabela:** exibe eventos ativos e total de eventos. **Detalhes do evento:** permite selecionar um evento e ver detalhamentos, filtros e métricas adicionais. |
| **Eventos de teste** | Permite verificar se eventos do app, navegador web ou servidor estão configurados e disparando corretamente. | Ajuda a depurar eventos quando houver atividade incomum. |
| **Diagnóstico** | Ajuda a descobrir e resolver problemas de integração. | Mostra recomendações para aprimorar seus eventos. |
| **Histórico** | Mostra o histórico do Pixel e da API de Conversões. | Inclui alterações feitas no Pixel ou na API de Conversões, quando foram feitas e quem as fez. |
| **Configurações** | Mostra detalhes da integração. As opções variam de acordo com o tipo de dado visualizado. | Visualizar identificação e proprietário dos dados. Visualizar controles e permissões de compartilhamento. Selecionar configurações de cookies. Gerenciar correspondência avançada. Usar a ferramenta de configuração de eventos. Configurar a API de Conversões. Controlar permissões de tráfego. Conectar CRM para leads de conversão. |

## Conversões personalizadas

Use a página Conversões personalizadas para criar, mensurar, otimizar ou compartilhar suas conversões personalizadas. No momento, as conversões personalizadas não estão disponíveis para eventos do app e de mensagens.

Para detalhes sobre criação e limitações, consulte também [Rastreamento de conversão](conversion-traking.md).

## Integrações de parceiros

Use a página Integrações de parceiros para conectar a conta de um parceiro e configurar eventos. Essas integrações podem ser usadas para web, apps, conversões offline e eventos de mensagens.

> **Observação:** o número total de eventos pode ser diferente entre a página de fontes de dados no Gerenciador de Eventos, a página Conversões personalizadas no Gerenciador de Eventos e o Gerenciador de Anúncios da Meta.

Se você é desenvolvedor, pode acessar o Meta for Developers para saber mais sobre o Pixel da Meta, a API de Conversões, o SDK do Facebook para iOS e Android e outras APIs, plataformas, produtos e SDKs.
